# Instructor script

Today we are learning a management and verification loop, not racing a coding
agent. A frontier agent could do this task faster. CS I is teaching the process
well enough that you can scale into unfamiliar tools in the wild.

We establish the folder and baseline, ask for one tiny change, inspect the
diff, and prove it with tests. The robot changed something. Prove it still
works. Write down what happened.

The Monty Hall payoff is prepared rather than pretending it appeared live.
That is an honest recording choice: one visible bite teaches scope and review;
the tested payoff teaches the program and the probability result. The deeper
process folder shows the larger attempts, the failed transport, and the
corrections.
