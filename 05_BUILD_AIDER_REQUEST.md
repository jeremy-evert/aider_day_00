# 05 — Build the Aider Request

Inside `jeremy_run_1`, create:

```text
AIDER_REQUEST.md
```

Put this in it:

```text
Change only hello.py.
Change the printed message from "Hello, world!" to "Hello, Aider!".
Do not add files and do not change anything else.

PREDICTION:
One line in hello.py should change.
No other file should change.
```

Read the prediction **before** launching Aider.

## Green light

You can say what should change before the machine acts.
