# Why the old EULA file was wrong

The locally present file `M365_Copilot_EULA_Terms_19Nov2025.pdf` is **not
published** in this repository. Its filename is not provenance, and it is not
the controlling SWOSU Copilot agreement.

The available mission evidence identifies the document as a Refinitiv/MSN
Money financial-data terms document, with financial-data publisher/content
provider notices rather than Microsoft Copilot contractual headings. It is
therefore a useful teaching example: a plausible filename can point to the
wrong service. It should not be called the SWOSU Copilot EULA, and it should
not be redistributed unless its copyright/license terms are independently
cleared.

The proper public artifact is the dated link-and-provenance record in this
folder. Microsoft's live licensing pages and SWOSU's live policy pages outrank
an unexplained local filename.
