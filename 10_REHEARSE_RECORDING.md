# 10 — Rehearse the Recording Cold

Reset mentally to the beginning and walk the entire route without skipping steps:

```text
FIND
→ CREATE
→ WRITE
→ RUN
→ BASELINE
→ PREDICT
→ AIDER
→ DIFF
→ PROOF
→ DECIDE
```

During the rehearsal, observe three things:

1. Did the launcher work on Grace without repair?
2. How long did the local model take?
3. Did Aider touch only what you predicted?

Fix only friction you actually observe.

Do not add extra curriculum merely because it might be useful someday.

## Green light

The complete route works from a cold start and is boring in the best possible way.

When that is true, freeze the exact recording-ready commit/tag before recording.
