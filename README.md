# Aider Day 0

This repository is the clean recording runway for the first Aider experience.

Start with:

[`00_MAP.md`](00_MAP.md)

Then follow the numbered cards in order. Build the actual rehearsal inside your own run folder, such as:

```text
jeremy_run_1/
```

The goal is intentionally small:

```text
FIND → CREATE → WRITE → RUN → BASELINE → PREDICT → AIDER → DIFF → PROOF → DECIDE
```

The previous experimental work is preserved in `jeremy-evert/aider_learning` and in this repository's Git history. This front door stays small on purpose.
